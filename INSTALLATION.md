# 📱 Installation Guide - Campus Commute Connect

## Installing on Windows

1. **Open in Browser**
   - Open Chrome or Edge browser
   - Navigate to `http://localhost:8080` (or your deployed URL)

2. **Install the App**
   - Look for the install icon (➕) in the address bar
   - Click "Install" or "Install Campus Commute Connect"
   - The app will be installed as a desktop application

3. **Launch the App**
   - Find "Campus Commute Connect" in your Start Menu
   - Or launch from the desktop shortcut
   - App will open in its own window without browser UI

---

## Installing on Android

1. **Open in Chrome**
   - Open Chrome browser on your Android device
   - Navigate to your app URL

2. **Add to Home Screen**
   - Tap the menu (⋮) in the top-right corner
   - Select "Add to Home screen" or "Install app"
   - Tap "Add" to confirm

3. **Launch the App**
   - Find the app icon on your home screen
   - Tap to open - it will run like a native app
   - Works offline after first visit!

---

## Features After Installation

✅ **Offline Access** - App works without internet (after first load)
✅ **Native Feel** - Runs in standalone mode without browser UI  
✅ **Auto Updates** - Service worker updates app automatically
✅ **Fast Loading** - Cached resources load instantly

---

## Deployment Options

### Option 1: Local Network
- Share your computer's IP address with other devices on the same WiFi
- Access via `http://YOUR_IP:8080`

### Option 2: Online Deployment
Deploy to platforms like:
- **Vercel** (recommended, free)
- **Netlify** (free)
- **Firebase Hosting** (free tier available)

Then users can install from the deployed URL!
